# 골목 붕어빵 — 사장님의 손맛 (v2)

독립 브라우저 타이쿤. 운영 사이트와 별개이며 배포 대상은 `dist/`의 HTML/CSS/JS 4개 파일입니다.

## 실행 및 검증

- `npm.cmd start` → http://127.0.0.1:4178
- `npm.cmd test` → 엔진 회귀 테스트 12개
- `reviews/v2-browser.js`: 브라우저 기본 조리, 품질, 판매, 일시정지, 정산, 재시작 통합 검증
- `reviews/v2-fixture.js` + `reviews/v2-advanced.js`: 로컬 전용 테스트 저장 데이터로 연구·장비·상권·고급 조리 검증. 운영 사이트에서 fixture를 실행하지 마세요.
- Vercel: `dist/`에서 `vercel.cmd --prod --yes --scope deokhwan`

## 플레이

한 판 120초. 메뉴와 화력을 선택한 뒤 빈 화구를 누릅니다. 초록 표시에서 뒤집고, 레시피에 따라 속을 채우고 마감 도구를 골라 조리한 다음 꺼내 손님에게 판매합니다.

- 메뉴 6종: 팥, 슈크림, 치즈, 초코, 인절미, 피자. 4종은 돈과 평판으로 연구합니다.
- 추천 화력·퍼펙트 뒤집기·빠른 충전·마감·수거에 따라 1~3성 품질. 보관 시간이 길면 품질이 감소합니다.
- 치즈: 충전+압착 / 초코: 토치 / 인절미: 충전+콩가루 / 피자: 충전+토치.
- 손님 7유형: 이웃, 학생, 직장인, 가족, 미식가, 단골, 배달 라이더. 수량, 인내, 팁, 선호 메뉴, 품질 요구, 복합 주문이 다릅니다.
- 장비 9종, 총 37단계: 동판, 숙성고, 난로, 온도계, 쇼케이스, 화구, 도구, 간판, 포장대.
- 운영 물품 4종: 차, 전단지, 코팅, 안심 영업권. 구매 후 사용 시 소모됩니다.
- 6개 상권으로 5회 확장. 판매가·유입량·미션 보상이 증가하며 확장 비용과 평판 조건도 높아집니다.
- 4일 주기 날씨, 3종 일일 미션, 4개 일회성 업적 보상.
- 재료비는 투입 시 발생하고 정산 시 차감합니다. 팥은 무료여서 자금 부족으로 게임이 막히지 않습니다.
- 매출 목표는 최고 기록과 상권에 연동된 보너스 목표입니다. 목표를 못 채워도 다음 날로 진행하고 수익을 보유합니다.

PC 단축키: 1~8 화구, Q/W 메뉴 순환, Space 일시정지. 모바일 터치 지원. 다른 탭으로 이동하면 자동 일시정지합니다.

## 저장

`golmok-bungeo-v2` localStorage에 영업 정산과 상점 구매를 저장합니다. 기존 `golmok-bungeo-v1`의 돈·영업일·최고 기록·손님 수·업그레이드를 자동 이전합니다. 기존 v1 키는 보존합니다. 새 게임 준비금은 5,000원이며 차와 코팅을 각각 1개 제공합니다. 영업 중간 상태는 저장하지 않습니다.

효과음은 Web Audio로 생성합니다. 그림은 인라인 SVG/CSS이며 외부 이미지가 필요 없습니다. Google Fonts 접속 실패 시 시스템 폰트를 사용합니다.
