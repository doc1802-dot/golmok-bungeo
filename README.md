# 골목 붕어빵

90초 영업, 팥·슈크림 굽기, 뒤집기, 손님 주문, 대기 시간, 콤보/팁, 업그레이드가 있는 독립 브라우저 게임입니다. 기존 운영 사이트와 별개입니다.

- 실행: `npm.cmd start` → http://127.0.0.1:4178
- 검증: `node --test game.test.mjs`
- 배포 파일: `dist/` (빌드 불필요)
- 조작: 재료 선택 → 빈 틀 클릭 → 뒤집기 표시 때 클릭 → 완성 시 클릭 → 주문 고객 클릭.
- PC 단축키: 1~6 화구, Q/W 재료, Space 일시정지. 터치 가능.
- 다른 탭으로 이동하면 자동 일시정지. 기록은 영업 종료/업그레이드 시 브라우저 localStorage에 저장합니다. 진행 중인 영업은 저장하지 않습니다.
- 효과음은 사용자가 소리를 켰을 때 Web Audio로 생성합니다. 폰트는 Google Fonts에서 불러오며 실패 시 시스템 폰트를 사용합니다. 모든 일러스트는 코드로 제작했습니다.
